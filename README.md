# SAP-C03: architecture decisions companion

Independent learner companion for **AWS Certified Solutions Architect – Professional, SAP-C03**. Prepared November 25, 2026. The preserved official transition reference identifies SAP-C03 as in use beginning November 17, 2026; do not use the older SAP-C02 blueprint as the current outline.

Read [Decision review](DECISION-REVIEW.md), use [Study workflow](STUDY-WORKFLOW.md), and verify details through [Official references](OFFICIAL-REFERENCES.md).

The focus is architecture reasoning across cloud design, security/governance, cost, resilience/migration and operational automation. This is not a question bank, answer key, copied architecture manual or reproduction of an AWS assessment. No paid AWS deployment is needed to use it. Optional experiments require an authorized sandbox, spending limits and an explicit teardown plan.

These materials are independently authored and not affiliated with or endorsed by AWS. They do not establish hands-on proficiency or predict a certification result. Product support depends on Region, service mode, engine and version. Official links come from preserved course references; live availability was not rechecked for this offline companion.
